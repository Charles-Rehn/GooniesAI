# Goonies AI

Official release downloads for Goonies AI.

Download the latest `GooniesAI.exe` from [Releases](https://github.com/Charles-Rehn/GooniesAI/releases/latest).
The main application requires a valid Goonies license. The optional second-PC
MAKCU receiver requires no license or HWID activation.

The updater-enabled main app checks for signed updates before opening, verifies
the download, and launches the new version while keeping its existing local
runtime and user data. Internet access is needed to check and download updates.

This repository distributes releases; it does not contain private application
source or update-signing keys. Each main-app release contains `GooniesAI.exe`
and its signed `update.json`. A standalone receiver may be provided separately.
